# Movies Reviews - Backend

API REST para la aplicación Movies Reviews.

## Tecnologías
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Bcrypt

## Funcionalidades
- Registro e inicio de sesión.
- Autenticación mediante JWT.
- CRUD de películas y géneros.
- Publicación y gestión de reseñas.
- Validación de datos y control de permisos.

## Instalación

1. Instalar las dependencias:
npm install

2. Crear el archivo .env y configurar las variables de entorno.

3. Iniciar el servidor:
npm run dev

El servidor se ejecuta en http://localhost:3000.
